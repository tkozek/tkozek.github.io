Projects

  • PrairieTest Exam Autobooker | Selenium, GCP, Docker, Python, GitHub Actions
    UBC has been transitioning to hosting exams for many core Computer Science courses via PrairieLearn in their Computer-Based Testing Facility. I wrote a script using Selenium with Python to automate my exam bookings for this platform. I containerized it with Docker, deployed on GCP, and interfaced with the Google Calendar API to prevent booking conflicts when possible.

  • Image Compressor | C++, GDB, CMake, Valgrind
    Built using hex trees in C++. Can be lossless or lossy, depending on the user inputs. Supported image manipulations such as flipping, copying, and greyscale.

  • Crossword Game -- GitHub Repo | Java, Swing
    A Scrabble game written in Java, created both terminal and graphical user interfaces. Supported save, load, and various types of in-game queries with a user-friendly design. Images and instructions available in README.
